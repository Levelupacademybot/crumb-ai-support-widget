How the assistant works

This page runs a lightweight retrieval engine right in your browser, so the demo works with no API key. The production setup swaps the matcher for an LLM call (Claude or OpenAI) grounded on the same FAQ.

1. Knowledge baseBusiness FAQ written by the owner, editable as plain JSON or a Google Sheet.
2. RetrievalFinds the most relevant FAQ entries for each question.
3. Grounded answerReplies only from the FAQ and shows the source it used.
4. Human handoffIf confidence is low, it collects an email and notifies the team.
